# Serdal — фирменный стиль кабинетов

Это обязательная спецификация интерфейса кабинетов учителя и ученика (а позже и админки).
Правила здесь — не рекомендации. Отступать от них можно только по прямой просьбе владельца продукта;
если задача требует того, чего здесь нет, — сначала спроси, потом расширь этот документ.

- Эталонные макеты: https://claude.ai/artifact/1sQ2v5WJTAFWF5durXXcNr (страницы «Ученик», «Учитель», «Вход и первые шаги», «Сценарии и окна», «Основа»).
- Перед любым экраном найди его макет и повторяй структуру, тексты и поведение. Нет макета — собирай из тех же компонентов по тем же правилам.
- Публичный сайт (`public/css/serdal-ru.webflow.css`, `resources/views/layout.blade.php`) — отдельный визуальный язык. Кабинетные правила к нему не применяются, кроме общих токенов цвета и шрифта.

## 1. Стек кабинетов

- Кабинеты — Livewire 3 + Blade + Tailwind на токенах ниже. **Filament в кабинетах не используется** (ни панели, ни их раскладка, ни классы `.fi-*`). Админка пока остаётся на Filament.
- Весь UI собирается из компонентов `resources/views/components/ui/*` (`<x-ui.card>`, `<x-ui.btn>`, `<x-ui.badge>`, `<x-ui.row>` …). Не верстай «с нуля» то, что уже есть компонентом. Новый повторяющийся элемент → новый компонент в `ui/` + строка в этом документе.
- Стили кабинетов: `resources/css/cabinet.css` + `tailwind.cabinet.config.js`. Никаких произвольных значений Tailwind (`p-[13px]`, `text-[#abc]`) — только токены.

## 2. Иерархия: три уровня

1. **Главное действие** — жёлтая кнопка. Не больше одной на экран (в окне — своя одна). Если на экране нет главного действия — жёлтой нет.
2. **Фокус-блок** — мятная карточка (`bg-mint`). Один на экран: то, ради чего страницу открыли.
3. **Всё остальное** — белые карточки с линией 12%, серые подписи, строки-ссылки со стрелкой.

## 3. Цвета (токены)

| Токен | Hex | Роль | Нельзя |
|---|---|---|---|
| `brand` | `#FFE500` | только главная кнопка | фон блоков, бейджи, текст |
| `ink` | `#202323` | текст, иконки, чёрная кнопка, активная вкладка | — |
| `muted` | `#5F6262` | подписи, неактивное меню | основной текст |
| `mint` | `#EBF5F4` | фокус-блок, активный пункт меню | больше одного блока на экран |
| `mint-2` | `#E3EFEE` | дорожки, подложки | кнопки |
| `soft` | `#F1F5F5` | нейтральный бейдж, плитки, сегменты | — |
| `line` | `#2023231F` | рамки и разделители | тени вместо рамок |
| `danger` | `#DC2626` | счётчики уведомлений | статусы, кнопки |
| `danger-bg` / `danger-fg` | `#FDE7E4` / `#A3261B` | бейдж «Проблема» | — |
| `ok-bg` / `ok-fg` | `#D3F8F3` / `#0E5A53` | бейдж «Результат» | — |
| `promo` | `#FFFBD6` | только плашка партнёрской программы | всё остальное |

## 4. Типографика

Шрифт Inter (400/500/600). На экране не больше 4 размеров (не считая цифр-акцентов).

| Роль | Размер / интерлиньяж / вес |
|---|---|
| h1 заголовок страницы | 36/44, 500, −0.8px (телефон 28/36) |
| h2 заголовок блока | 20/28, 500 |
| t1 название в списке | 16/24, 500 (в плотных списках 15/20) |
| t2 подпись | 14/20, 400, `muted` |
| t3 мелкая подпись | 13/16, `muted` |
| акцент-цифра | 24–28, 500 (суммы, итог) |

Срочное внутри подписи (время, срок) — жирным `ink` 600, **не бейджем**: «Английский · **сдать до завтра, 20:00**».

## 5. Отступы, радиусы, размеры

- Отступы — только **4 · 8 · 12 · 16 · 24 · 32 · 48**. 4 — внутри текста; 8 — между соседями (кнопки, бейджи); 12 — картинка+текст; 16 — строки списка, заголовок блока→содержимое, поля экрана на телефоне; 24 — поля карточки и между карточками; 32 — шапка→контент; 48 — поля страницы на компьютере.
- Радиусы — только **8 · 12 · 16 · 24 · круг**. 12 — кнопки, поля, пункты меню, аватары; 24 — карточки; 16 — вложенные блоки; 8 — сегменты, чекбоксы; круг — бейджи, счётчики.
- Вложенный радиус = внешний − отступ (карточка 24 − отступ 8 → 16).
- Высоты: кнопки **36 / 44 / 52**, пункт меню 44, поле ввода 44 (формы входа 52), аватар 40 (в шапке карточки человека 64/радиус 16), бейдж 24, счётчик 20. Иконки 16 в тексте, 20 в меню и кнопках, stroke 1.8.
- Ширины-токены: сайдбар `sidebar` 264, колонка диалогов `dialogs` 360, сообщение в чате `bubble` 480, боковая панель `drawer` 440, окна `modal-s/m/l` 480/640/960, форма `form` 640. `screen` — высота экрана (сайдбар, «Сообщения»).
- Текст в полях ввода на телефоне — не меньше 16 (`t1`), иначе iOS увеличивает страницу при фокусе.

## 6. Компоненты

- **Кнопки — ровно три стиля**: жёлтая `primary` (главное), чёрная `dark` (важное второе: оплата, создание; не больше одной на экран; в окне — разрушительное действие), с обводкой `outline` (всё остальное). Плюс текстовая ссылка (подчёркнута, `line` 30%). Других стилей нет.
- **Карточка**: радиус 24, отступ 24, рамка `line`. Шапка карточки: h2 + справа ссылка/кнопка 36, мин. высота 36, затем 16 до содержимого.
- **Строка списка**: отступ 16/16, линия сверху, последний ряд без нижнего отступа; вся строка — ссылка со стрелкой. Не кнопка в каждой строке.
- **Шапка страницы**: [← назад] → h1 → одна строка фактов (дата, сколько, срок) — справа 1–3 действия по иерархии. Подзаголовок не пересказывает заголовок.
- **Вкладки** — подчёркивание 2px `ink`, без заливки. **Фильтры/виды** — сегменты (подложка `soft` 12, активный белый 8).
- **Сайдбар** (264): логотип + колокольчик уведомлений (красная точка при новых) → меню → [промо] → «Поддержка» → профиль. Активный пункт — `mint`, 600. Счётчики — красные.
  - Учитель: Сегодня · Расписание · Сообщения · Ученики · Задания · Материалы · Записи · Отзывы.
  - Ученик: Главная · Расписание · Задания · Сообщения · Материалы · Записи · Оплата.
  - Телефон: верхняя панель (логотип, колокольчик) + нижняя панель вкладок (Главная, Расписание, Задания, Сообщения, Ещё).
- **Бейджи статусов** (радиус круг, 24): `danger` — только проблема (Просрочено, На доработке, Не оплачено в прошлом); `ok` — результат (Оценка 5, Оплачено сразу после действия); `neutral` — остальное. **Показываем исключения, а не норму**: «Оплачено» в каждой строке — шум.
- **Окно (модальное)**: затемнение `#202323B8`, отступ 32, окно белое радиус 24; ширины 480 (подтверждение) / 640 (форма) / до 960 (превью). Шапка: h2 + одна строка пояснения + крестик 44. Тело 24. Подвал: слева пояснение/ссылка, справа «Отмена» (outline) + главная (жёлтая; для необратимого — чёрная с последствиями в тексте).
- **Тост**: белый, радиус 16, тень, внизу по центру, мятная галочка, 15px, крестик; для обратимых действий — «Отменить». После перехода на другую страницу — `session()->flash('toast', '…')`.
- **Меню действий «⋯»** (`x-ui.menu` + `x-ui.menu-item`): кнопка 36, список белый радиус 12, рамка `line`, пункты 36. Для второстепенных действий над элементом (изменить, удалить), когда отдельные кнопки — шум.
- **Боковая панель** (уведомления): справа 440, на всю высоту, радиус 24 слева, затемнение как у окна; на телефоне — на весь экран. Шапка h2 + крестик, группы «Новые» / «Раньше» (подпись 13/600 `muted`), непрочитанное — красная точка 8, подвал со ссылкой и текстовой кнопкой.
- **Сообщения**: колонка диалогов 360 (поддержка закреплена сверху, линия, дальше — новые сверху; жирное имя и красный счётчик у непрочитанного) + переписка. Свои сообщения — `mint` справа, чужие — белые с рамкой слева, радиус 16, до 480; время и галочки (✓ отправлено, ✓✓ прочитано) 12 `muted` внизу справа; разделители дней — нейтральный бейдж по центру. Раскладка экрана — `bare` (без полей страницы), на телефоне переписка открывается поверх списка.
- **Пустое состояние**: внутри блока — одна строка «Пока пусто — …»; пустой раздел — иконка на плитке 64/16, заголовок 20, одна строка, одна кнопка.
- **Графики успеваемости**: вложенные кольца (посещаемость `#2A78D6`, задания в срок `#1BAF7A`, качество знаний `#EDA100`), дорожка — тот же цвет 16%, легенда всегда видна (точка, название, исходные цифры, процент). Эти цвета — только для графиков.

| `x-ui.list`, `x-ui.row`, `x-ui.text`, `x-ui.em` | список строк, строка (с `href` — ссылка со стрелкой), двухстрочный текст, срочное жирным |

| `x-ui.badge`, `x-ui.count` | бейдж статуса (danger/ok/neutral), красный счётчик |
| `x-ui.avatar`, `x-ui.date-tile`, `x-ui.file-tile` | аватар с закреплённым цветом, плитка даты 48, плитка файла 40 |
| `x-ui.tabs`, `x-ui.seg` | вкладки (подчёркивание), сегменты (фильтры, виды) — через `model` Livewire |
| `x-ui.field` | поле формы: подпись, ошибка, подсказка; `rows` > 0 — textarea |
| `x-ui.modal`, `x-ui.toast` | окно (`width` s/m/l, слоты `footer`, `note`); тост — `$this->dispatch('toast', message: '…')` |

## 7. Текст

- Тон: на «вы», тёплый, коротко. Одно предложение там, где хочется два.
- Словарь (обязательно):

| Говорим | Не говорим |
|---|---|
| Занятие | урок, сессия, комната, встреча |
| Ученик, ученица | студент, участник |
| Учитель | преподаватель, тьютор |
| Начать занятие · Завершить занятие · Войти в класс | Начать, Остановить, Запустить |
| Запись занятия | BBB, ID встречи, meeting |
| сегодня в 16:00 · завтра · чт, 3 октября · до 12 октября | 03.10.2026 18:30 · до 12.10 |

- Никаких технических полей в интерфейсе (ID, meeting_id, JSON, «Параметры», «удалённые»).
- Пустые состояния и ошибки объясняют, что делать дальше.

## 8. Запрещено («AI-слоп»)

- Карточки-памятки и «объяснялки» («Как это работает», «Что будет дальше» из 3 шагов, «Как получить больше…»).
- Иконка на плитке перед каждым заголовком/пунктом; сетки «преимуществ» с иконками; нумерованные кружки без необходимости.
- Надпись капсом над заголовком; подзаголовок-пересказ; маркетинговые фразы в кабинете («всё в одном месте», «быстро и удобно»).
- Счётчики «· N» в каждом заголовке, бейджи на всём подряд.
- Карточка в карточке; 4+ карточки в колонке; одинаковые по весу блоки.
- Градиенты, декоративные тени, разноцветные плашки, эмодзи.
- Больше одной жёлтой кнопки; жёлтый не на главной кнопке.
- Значения вне шкал отступов/радиусов/размеров; цвета вне таблицы токенов.

## 9. Проверка перед сдачей экрана

1. Есть макет → структура и тексты совпадают. 2. Одна жёлтая, один фокус-блок. 3. Все отступы/радиусы/размеры из шкал, цвета из токенов. 4. ≤ 4 размеров шрифта. 5. Словарь и даты. 6. Нет пунктов из раздела 8. 7. Работает на ширине 390 (телефон) и 1440.
